## 🛠️ 本地运行指引

本项目为纯前端静态工程（HTML5 + ES Modules + CSS3），无需 Node.js 打包编译，直接启动静态服务器即可运行：

```bash
# 1. 克隆本仓库
git clone https://github.com/Alastair06/zhimoujue.git

# 2. 进入项目目录
cd zhimoujue

# 3. 启动本地静态服务器（以 Python 为例）
python3 -m http.server 8888
```

在浏览器中打开 `http://127.0.0.1:8888` 即可畅玩！
