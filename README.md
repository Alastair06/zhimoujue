## 🌟 核心特色与玩法系统

### 1. ⚔️ 双雄会盟 · 同屏双人实时对决 (Local PvP)
- **支持 PC 双人键盘 / iPad 触屏面对面对战**：
  - **🟦 P1 蓝方（汉室联盟）**：
    - 快捷键：`1` (步兵), `2` (弓兵), `3` (铁骑), `4` (投石车), `Q` (关羽), `W` (赵云)
  - **🟥 P2 红方（魏武雄师）**：
    - 快捷键：`7` (步兵), `8` (弓兵), `9` (铁骑), `0` (投石车), `O` (吕布), `P` (曹操)，亦支持小键盘 `1~6`
- **绝对对称公平竞技**：双方初始军饷 160、增长速率 +12/s，主城血量各 2500，全凭战场微操与出兵节奏破寨决胜！

### 2. 📱 100% 离线 PWA 支持（独立桌面 App 体验）
- **对齐《太阁》离线架构**：
  - 内置 Service Worker 智能缓存引擎与 Web App Manifest 规范；
  - **iPad / iPhone (Safari)**：点击“分享 ↗️ ➡️ **添加到主屏幕**”，桌面即生成《吞食三国》独立图标；
  - **脱离浏览器地址栏**：享受全屏独占沉浸体验，即使拔掉网线、处于无信号山区或飞行模式，照样天天秒开畅玩！

## 🛠️ 本地运行指引

本项目为纯前端静态工程（HTML5 + ES Modules + CSS3），无需任何构建编译：

```bash
# 1. 克隆仓库
git clone https://github.com/Alastair06/zhimoujue.git

# 2. 进入目录
cd zhimoujue

# 3. 启动本地服务器
python3 -m http.server 8888
```

在浏览器打开 `http://127.0.0.1:8888` 即可畅玩！
